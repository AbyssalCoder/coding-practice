## HTTP Basics

### Common methods
- `GET` — Retrieve a resource
- `POST` — Submit data
- `PUT` — Replace a resource
- `PATCH` — Partial update
- `DELETE` — Remove a resource

### Status codes
| Range | Meaning       | Example          |
|-------|---------------|------------------|
| 2xx   | Success       | 200 OK           |
| 3xx   | Redirect      | 301 Moved        |
| 4xx   | Client error  | 404 Not Found    |
| 5xx   | Server error  | 500 Internal     |
